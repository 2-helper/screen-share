📌 이 링크는 PC에서 크롬이나 엣지로 열어 주세요. (휴대폰·카톡 안 브라우저에서는 작동하지 않아요)

① 내 화면 보여주기 (설명하는 사람)

버튼을 누르고 보여줄 화면을 고르면 접속코드가 나옵니다. 코드를 상대방에게 알려주세요.

------
↑ 이 6자리 코드를 상대방에게 알려주세요
  1. '화면 공유 시작' 클릭 → '전체 화면' 선택 → '공유'
  2. 나온 코드를 전화·카톡으로 전달
  3. 설명할 창을 띄워 둔 뒤 이 창으로 돌아와 숫자 1 키 또는 '판서 모드' 버튼을 누르면 판서가 시작됩니다
  4. 바로 전 화면 위에 마우스를 누른 채 움직이면 펜으로 그려집니다
  5. 끝나면 Esc 또는 다시 Alt+Tab → 판서가 닫히고 원래 창으로 돌아갑니다

② 상대방 화면 보기 (안내 받는 분)

전달받은 6자리 코드를 넣고 '연결하기'를 누르세요.

  1. 상대방이 먼저 '화면 공유 시작'을 해야 합니다
  2. 코드 입력 후 '연결하기' 클릭
  3. 화면이 뜨면 '전체화면'으로 크게 볼 수 있습니다
